# 1935–36 Exhibition Catalogue Data Visualisation

An interactive data visualisation project that transforms the printed catalogue of the 1935–36 International Exhibition of Chinese Art at London's Royal Academy into a structured, searchable and explorable dataset.

## The project explores the exhibition from four perspectives:

- What was exhibited — categories, periods and object types
- Who contributed — lenders and their contributions
- Where objects came from — geographic distribution
- How the exhibition was organised — spatial layout of the exhibition halls

The project combines data extraction, cleaning, classification and modelling with interactive visualisation to reveal patterns and relationships within the historical exhibition catalogue.

## Interactive Visualisations

- Temporal & Categorical Distribution
- Lender Type Stacked Bar Chart
- Lender Contribution Explorer
- Geographic Distribution Map
- Exhibition Hall Layout Explorer
